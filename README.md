# Cybersecurity Portfolio

Acest repository conține proiecte și exerciții practice din domeniul securității cibernetice, realizate în cadrul procesului meu de învățare. Documentele demonstrează competențe în administrarea Linux, interogarea bazelor de date, automatizarea cu Python, evaluarea riscurilor, răspunsul la incidente și analiza vulnerabilităților.

## Competențe demonstrate

- Administrarea și securizarea sistemelor Linux
- Gestionarea permisiunilor și a accesului la fișiere
- Interogarea și filtrarea datelor cu SQL
- Programare și automatizare cu Python
- Evaluarea riscurilor și a controalelor de securitate
- Identificarea și documentarea incidentelor
- Raportarea vulnerabilităților și recomandarea remediilor
- Lucrul cu principii de conformitate și securitate operațională
